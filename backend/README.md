# OAU Student Complaint & Maintenance Reporting System

This is a web-based system designed to help students of Obafemi Awolowo University (OAU) report campus maintenance issues, track their complaints, and receive updates on their resolution.

## About the Project

Students often face maintenance issues such as faulty lights, leaking pipes, damaged facilities, water problems, and other problems. Reporting these issues and tracking their progress can be difficult without a centralized process.

The OAU Student Complaint & Maintenance Reporting System aims to provide a centralized platform where students can submit complaints, authorized staff can manage reports, and students can monitor the status of their submissions.

This project is being developed as a Student Work Experience Program (SWEP) group project. It is not an officially adopted OAU system unless subsequently approved by the university.

## Project Objectives

- Provide a simple way for students to report campus maintenance issues.
- Enable students to track the status of their complaints.
- Help authorized staff review, assign, and manage reported issues.
- Improve visibility into the progress and resolution of complaints.
- Maintain a record of complaints and their status updates.

## Planned Features

- **Student authentication:** Student registration and login.
- **Complaint submission:** Submit a complaint with a title, description, category, location, and optional image.
- **Complaint tracking:** View complaint status: Pending, In Progress, Resolved, or Rejected.
- **Administrative dashboard:** Review complaints, assign issues, and update their status.
- **Notifications:** Notify students when their complaints receive updates.
- **Complaint history and reports:** View previous complaints and summarize reported issues.

*These are planned features and may change as the project develops.*

## Technology Stack

The proposed technologies are:

- **Frontend:** HTML, CSS and JavaScript
- **Backend:** Python with Flask
- **Database:** MySQL
- **Version Control:** Git and GitHub

The final stack may be updated as the team agrees on the implementation.

## Contributing

This project is developed collaboratively by a student team.

Contributors should follow the project's GitHub workflow:

1. Check the available GitHub Issues and select an assigned task.
2. Create a branch for the task.
3. Make changes and commit them with clear messages.
4. Push the branch to GitHub.
5. Open a pull request for review before merging into `main`.

Do not commit passwords, API keys, environment secrets, or private student information.
